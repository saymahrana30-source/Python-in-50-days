# Python 50-Day Challenge

A full 50-day Python learning plan — fundamentals through a shipped capstone project — tracked daily as a public GitHub portfolio piece.

## Roadmap

| Weeks | Focus |
|-------|-------|
| Days 1–10  | Core fundamentals (variables, control flow, functions, data types) |
| Days 11–20 | OOP (classes, inheritance, file I/O, exceptions, decorators) |
| Days 21–30 | Data structures & problem solving (recursion, sorting, searching, complexity) |
| Days 31–40 | Libraries & real tools (requests, pandas, APIs, regex, web scraping) |
| Days 41–50 | Capstone project — planning, build, tests, docs, deployment |

## Structure

Each day gets its own folder:

```
dayNN/
  README.md        # topics, notes, today's challenge, interview questions
  exercises.py      # attempt the challenge here first
  solutions.py       # reference solution
```

`docs/Python_50_Day_Planner.pdf` has the entire plan (all 50 days) in one document — useful for offline reading or printing.

## How to run any day

```bash
python dayNN/solutions.py
```

## Interview Prep

Every day includes 2 interview-style questions tied to that day's topic. By Day 50 you'll have ~100 Q&As covering fundamentals through OOP, algorithms, and real-world tooling — a solid personal interview prep bank.
